# User Experience Test Phase: Issues & Test Results

## 1. Overview
This document tracks the issues faced during the User Experience (UX) Phase testing, with a heavy focus on user feedback loops, document generation, and system notifications.

---

## 2. Issues Encountered & UX Requirements

### 2.1. System Notifications & Email Triggers
- **Requirement**: We need to thoroughly check that notifications and emails are being generated and sent correctly at all major system steps. 
- **Critical Triggers**:
  - **Recruitment Workflow**: Status changes (e.g., shortlisted, interviewed, hired).
  - **Offers**: When an offer is extended, accepted, or rejected.
  - **Contract Placement**: When a contract is created, funded, or closed.
  - **Account Deletion**: Sending a final confirmation or goodbye email when an account is deleted.

### 2.2. Document Generation (PDFs)
- **Requirement**: The system must dynamically generate professional, branded documents/letters for the users at key milestones.
- **Critical Documents**:
  - **Offer Letters**: Automatically generated when an offer is sent.
  - **Invoices**: Automatically generated for financial transactions (e.g., escrow funding, payment released).

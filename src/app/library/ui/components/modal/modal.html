1. Modal Variant - Without Icons

Used for simple confirmations and basic actions. All modals use Medium size.

Block Client?

Do you want to block this client? The client will not be able to contact or hire you until you unblock them.

Unblock Client?

Do you want to unblock this client? The client will be able to contact and hire you again.

Archive Contract?

Do you want to archive this contract? You can view it in the archive section whenever you need.

Delete Post?

Are you sure you want to delete this post? This action cannot be undone and all related data will be permanently removed.

Delete Contract?

Are you sure you want to delete this contract? This action cannot be undone and all related records will be permanently removed.

Delete User?

Are you sure you want to delete this user? This action cannot be undone and all user data will be permanently removed.
